## Этап 1: Предсказание структуры с помощью AlphaFold2

### Что такое AlphaFold2

AlphaFold2 — это нейросетевая система от DeepMind для предсказания 3D структуры белков по аминокислотной последовательности. ColabFold — это упрощенная версия AlphaFold2, работающая в Google Colab.

### Подготовка последовательности

Создал файл `sequence.fasta`:
```fasta
>kozoliy_protein
MDADVISFEASRGDLVVLDAIHDARFETEAGPGVYDIHSPRIPSEKEIEDRIYEILDKIDVKKVWINPDCGLKTRGNDETWPSLEHLVAAAKAVRARLDK
```

### Использование ColabFold

**Ссылка на ноутбук:** https://colab.research.google.com/github/sokrypton/ColabFold/blob/main/AlphaFold2.ipynb

#### Шаг 1: Создание копии ноутбука

В меню Google Colab:
```
File → Save a copy in Drive
```

Переименовал в: `AlphaFold2_Kozoliy_Assignment5`

#### Шаг 2: Настройка параметров

В ноутбуке заполнил следующие поля:

**query_sequence:**
```
MDADVISFEASRGDLVVLDAIHDARFETEAGPGVYDIHSPRIPSEKEIEDRIYEILDKIDVKKVWINPDCGLKTRGNDETWPSLEHLVAAAKAVRARLDK
```

**jobname:**
```
Kozoliy_Assignment5_AlphaFold2
```

**Остальные параметры:**
- `num_relax`: 0
- `template_mode`: none
- `msa_mode`: mmseqs2_uniref_env
- `model_type`: auto
- `save_all`: ✓ (включено)

#### Шаг 3: Запуск предсказания

В меню:
```
Runtime → Run all
```

Процесс занял примерно **10-12 минут** и прошел через следующие этапы:
1. Установка зависимостей (~2 мин)
2. Поиск гомологичных последовательностей (MSA) (~3 мин)
3. Предсказание структуры (~5 мин)
4. Визуализация и сохранение результатов (~2 мин)

### Интерпретация RMSD

**RMSD = 1.524 Å** находится в диапазоне **"очень похожие структуры"** (1-2 Å).

**Классификация по RMSD:**
- < 1 Å → Практически идентичные структуры
- **1-2 Å → Очень похожие структуры** ← НАШИ РЕЗУЛЬТАТЫ
- 2-3 Å → Похожие структуры
- 3-5 Å → Умеренное сходство
- > 5 Å → Существенные различия

## Сравнение методов предсказания

### AlphaFold2

**Принцип работы:**
- Использует множественное выравнивание последовательностей (MSA)
- Учитывает эволюционную информацию

**Преимущества:**
- Очень высокая точность для белков с известными гомологами
- Хорошо предсказывает контакты между остатками

**Для нашего белка:**
- Высокая уверенность (pLDDT > 85) в большинстве регионов
- Стабильная геометрия всех элементов вторичной структуры

### OmegaFold

**Принцип работы:**
- Работает без MSA (на основе языковых моделей белков)
- Использует предобученную модель OmegaPLM
- Быстрее AlphaFold2

**Преимущества:**
- Не требует поиска гомологов
- Хорош для уникальных белков без родственников
- Быстрое предсказание

**Для нашего белка:**
- Сопоставимая точность с AlphaFold2
- Слегка большая вариативность в петлях (но всё равно RMSD < 2 Å)

### Консенсус методов

Оба метода **независимо** и **согласованно** предсказали:
- Общую топологию белка
- Расположение всех α-спиралей и β-листов
- Пространственную ориентацию структурных элементов
- Упаковку гидрофобного ядра

**RMSD 1.524 Å подтверждает высокую надежность обоих подходов.**
