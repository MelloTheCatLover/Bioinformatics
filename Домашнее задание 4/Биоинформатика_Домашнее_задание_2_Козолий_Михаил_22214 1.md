## Установка и настройка UCSF Chimera

### Шаг 1: Скачивание и установка

1. Перейти на сайт: https://www.cgl.ucsf.edu/chimera/download.html
2. Выбрать версию **UCSF Chimera** 
3. Скачать установочный файл
4. Установить программу стандартным способом

**Использованная версия:** UCSF Chimera 1.19 (build 42556)

**Способ 1: Прямая загрузка из базы данных PDB**

Через меню:
```
File → Fetch by ID → Ввести "1TIM" → Fetch
```

Через командную строку:
```chimera
open 1TIM
```

**Способ 2: Загрузка скачанного файла**

Через меню:
```
File → Open → Выбрать файл 1tim.pdb
```

### Шаг 3: Базовые настройки

`Удобнее работать через командую строку, в базовой режиме она недоступна, но ее можно открыть с помощью интерфейса:`

```
facorites -> Command Line
```

**Установка белого фона** (важно для качественных изображений):

Через командную строку:
```chimera
set bg_color white
```

**Центрирование структуры:**

## Создание визуализаций

Всего нужно создать **5 типов визуализаций** + **2 варианта раскраски**.

---

### Визуализация 1: Wireframe (Каркасная модель)

Показывает все атомы и связи между ними.

**Через меню:**
```
Actions → Ribbon → hide
Actions → Atoms/Bonds → show
Actions → Atoms/Bonds → wire
```

**Через командную строку:**
```chimera
~ribbon
display
represent wire
color byatom
```


---

### Визуализация 2: Backbone (Основная цепь)

Показывает только C-alpha атомы главной цепи белка.

**Через меню:**
```
Select → Structure → backbone → full
Actions → Atoms/Bonds → show only
Actions → Atoms/Bonds → balls and stick
```

**Через командную строку:**
```chimera
~display
display :*.ca
represent sphere
color byatom
```


---

### Визуализация 3: Spacefill (CPK модель)

Показывает атомы как сферы Ван-дер-Ваальса (space-filling модель).

**Через меню:**
```
Actions → Atoms/Bonds → show
Actions → Atoms/Bonds → sphere
Actions → Color → by element
```

**Через командную строку:**
```chimera
~ribbon
display
represent cpk
color byatom
```


---

### Визуализация 4: Ribbons (Ленточная модель)

Показывает вторичную структуру белка (альфа-спирали и бета-листы).

**Через меню:**
```
Actions → Ribbon → show
Actions → Atoms/Bonds → hide
Actions → Color → by secondary structure
```

**Через командную строку:**
```chimera
ribbon
~display
colorss
```

Или с радужной раскраской:
```chimera
ribbon
~display
rainbow
```


---

### Визуализация 5: Molecular Surface (Молекулярная поверхность)

Показывает внешнюю доступную поверхность молекулы.

**Через меню:**
```
Actions → Surface → show
Actions → Atoms/Bonds → hide
Actions → Ribbon → hide
```

**Через командную строку:**
```chimera
surface
~display
~ribbon
color byatom
```

## Раскраска структур

### Раскраска 1: CPK (по элементам)

Стандартная цветовая схема по типам атомов:
- Углерод (C) — серый
- Кислород (O) — красный
- Азот (N) — синий
- Сера (S) — желтый

**Применить CPK раскраску:**

Через меню:
```
Actions → Color → by element
```

Через командную строку:
```chimera
color byatom
```

---

### Раскраска 2: По доменам (цепям)

Триозофосфат изомераза в структуре 1TIM — это димер (две цепи: A и B).

**Вариант 1: Раскраска цепей разными цветами**

Через командную строку:
```chimera
ribbon
~display
color red :.a
color blue :.b
```

**Вариант 2: Раскраска по участкам структуры**

Для цепи A:
```chimera
color yellow :1-80
color green :81-160
color cyan :161-247
```

## Создание изображения публикационного качества

Для финального изображения я использовал комбинацию ленточной модели и полупрозрачной молекулярной поверхности с улучшенным рендерингом.

### Полный код для публикационного изображения:
```chimera
# Очистка от лишних молекул воды
delete solvent

# Базовая настройка
~display
ribbon
rainbow

# Белый фон
set bg_color white

# Добавление полупрозрачной поверхности
surface
surftransparency 75

# Улучшение визуального качества
set silhouette
set silhouetteWidth 2.5
set subdivision 5

# Настройка освещения
lighting mode two-point

# Эффект глубины резкости
set depthCue
set dc_color white
set dc_start 0.4
set dc_end 1.0
```

**После настройки ракурса вручную, сохраняем:**
```chimera
copy file publication_quality.png width 4000 height 4000 supersample 4 png
```

### Альтернативные варианты для публикационного качества:

**Вариант с контрастными цепями:**
```chimera
delete solvent
~display
ribbon
color red :.a
color dodger blue :.b
set bg_color white
surface
surfcolor gray
surftransparency 70
set silhouette
set silhouetteWidth 2.5
set subdivision 5
lighting mode two-point
set depthCue
set dc_color white
```

**Вариант с выделением активного центра:**
```chimera
delete solvent
~display
ribbon
rainbow
set bg_color white
display :13,95,165
represent sphere :13,95,165
color yellow :13,95,165
surface
surfcolor gray
surftransparency 75
set silhouette
set silhouetteWidth 2
set subdivision 5
lighting mode two-point
```

## Действия, которые я использовал, при создании изображений

### Управление камерой:
- **Вращение:** Левая кнопка мыши + движение
- **Перемещение:** Средняя кнопка мыши (или Shift + левая кнопка)
- **Масштаб:** Колесико мыши

### Изменение толщины лент:
```chimera
ribscale licorice 1.5
```

### Изменение прозрачности поверхности:
```chimera
surftransparency 60   # менее прозрачная
surftransparency 80   # более прозрачная
```



### Проверка версии Chimera:
```chimera
version
```

## Возможные проблемы и решения

При прочтении инструкций к ПО столкнулся с несколькими проблемами, которые решил в процессе работы. Самые актуальные по моему мнению:
### Проблема 1: "Color byss is undefined"
**Решение:** Используйте `colorss` или `rainbow` вместо `color byss`, как альтернативу

### Проблема 2: "no such set variable: keyLightIntensity"
**Решение:** Эта команда не поддерживается в Chimera 1.19, можно использовать только `lighting mode two-point`, как альтернативу


### Проблема 3: Плоские изображения
**Решение:** 
```chimera

lighting mode two-point
```
