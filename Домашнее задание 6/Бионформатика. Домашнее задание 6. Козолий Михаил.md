## Часть 1: Информация о препарате

### Действующее вещество

**Альбутерол (Albuterol)** — также известен под международным непатентованным названием **сальбутамол** (Salbutamol).

**Химические характеристики:**
- Химическая формула: C₁₃H₂₁NO₃
- Молекулярная масса: 239.31 г/моль
- SMILES: `CC(C)(C)NCC(O)C1=CC(CO)=C(O)C=C1`

### Область применения

Альбутерол применяется для лечения следующих заболеваний:

1. **Бронхиальная астма** — купирование и профилактика приступов бронхоспазма
2. **Хроническая обструктивная болезнь лёгких (ХОБЛ)** — симптоматическое лечение
3. **Бронхоспазм при физической нагрузке** — профилактика
4. **Острый бронхит с бронхообструктивным синдромом**
5. **Эмфизема лёгких** — в составе комплексной терапии

**Формы выпуска:** дозированные аэрозоли для ингаляций, растворы для небулайзера, таблетки, сиропы.

### Молекулярный механизм действия

Альбутерол является **селективным агонистом β₂-адренорецепторов**. Механизм действия включает следующие этапы:

**Этап 1: Связывание с рецептором**
- Молекула альбутерола связывается с β₂-адренорецептором на поверхности гладкомышечных клеток бронхов
- Связывание происходит в ортостерическом сайте рецептора

**Этап 2: Активация G-белка**
- Связывание лиганда вызывает конформационные изменения рецептора
- Это приводит к активации стимулирующего G-белка (Gs)
- α-субъединица Gs связывает ГТФ и диссоциирует от βγ-субъединиц

**Этап 3: Повышение уровня цАМФ**
- Активированная α-субъединица Gs стимулирует аденилатциклазу
- Аденилатциклаза катализирует превращение АТФ в циклический АМФ (цАМФ)
- Внутриклеточная концентрация цАМФ повышается

**Этап 4: Активация протеинкиназы А**
- Повышенный уровень цАМФ активирует протеинкиназу А (PKA)
- PKA фосфорилирует множество внутриклеточных белков-мишеней

**Этап 5: Расслабление гладкой мускулатуры**
- PKA фосфорилирует киназу лёгких цепей миозина (MLCK), снижая её активность
- Происходит снижение внутриклеточной концентрации кальция
- Гладкая мускулатура бронхов расслабляется
- Дыхательные пути расширяются (бронходилатация)

**Схема сигнального каскада:**
```
Альбутерол → β₂-AR → Gs-белок → Аденилатциклаза → ↑цАМФ → PKA → ↓Ca²⁺ → Бронходилатация
```

## Часть 2: Молекулярный докинг

### Что такое молекулярный докинг

Молекулярный докинг — это вычислительный метод, позволяющий предсказать предпочтительную ориентацию и положение молекулы (лиганда) при связывании с белком-мишенью (рецептором). Метод используется для:

- Предсказания структуры комплекса лиганд-рецептор
- Оценки силы связывания (scoring)
- Виртуального скрининга библиотек соединений
- Рационального дизайна лекарственных препаратов

### Использованный инструмент: LaboDock

### Шаг 4: Параметризация лиганда

Запустил ячейку **"Parameterise ligand with Gasteiger charges"**.

**Код для исправления (новая ячейка):**

```python
import os
from rdkit import Chem
from rdkit.Chem import AllChem

# Пути к файлам
LIG_sdf_lFile = '/content/1GQ4/LIGAND/Albuterol.sdf'
LIG_dFLD = '/content/1GQ4/DOCKING/Albuterol'
LIG_pdbqt_dFFile = '/content/1GQ4/DOCKING/Albuterol/Albuterol.pdbqt'

# Проверка и создание SDF если нужно
if not os.path.exists(LIG_sdf_lFile):
    SMILES = 'CC(C)(C)NCC(O)C1=CC(CO)=C(O)C=C1'
    mol = Chem.MolFromSmiles(SMILES)
    mol = Chem.AddHs(mol)
    AllChem.EmbedMolecule(mol, randomSeed=42)
    AllChem.MMFFOptimizeMolecule(mol)
    writer = Chem.SDWriter(LIG_sdf_lFile)
    writer.write(mol)
    writer.close()

# Создание папки и конвертация в PDBQT
os.makedirs(LIG_dFLD, exist_ok=True)
!obabel {LIG_sdf_lFile} -O {LIG_pdbqt_dFFile} --partialcharge gasteiger -h

# Исправление chain ID
with open(LIG_pdbqt_dFFile, 'r') as f:
    data = f.read()
data = data.replace('  UNL  ', '  UNL A')
with open(LIG_pdbqt_dFFile, 'w') as f:
    f.write(data)

print(f'✓ PDBQT создан: {LIG_pdbqt_dFFile}')
```

Результат:
